# 라이츠 아웃 3D

브라우저에서 바로 하는 3D 레이싱 게임입니다. 실제 서킷 24곳과 가상 서킷 4곳을 달릴 수 있습니다.

- 휴대폰(아이폰: Safari의 '홈 화면에 추가', 안드로이드: Chrome의 '앱 설치')과 PC(Chrome·Edge의 '앱 설치')에서 앱처럼 설치할 수 있습니다.
- 한 번 열고 나면 인터넷이 없어도 실행됩니다.
- 게임 주소: 이 저장소의 Settings → Pages 화면에 나오는 주소입니다.

## 수정하는 방법
- index.html 등 게임 파일을 고친 뒤 `python3 make-sw.py`로 sw.js를 다시 만들어 함께 올립니다.
- Claude나 Claude Code에 수정을 맡길 때의 규칙은 CLAUDE.md에 있습니다.
